# password-strength-analyser
 A Python project that analyses and evaluates password strength based on multiple security criteria.
# Features
 Checks for uppercase, lowercase, numbers, and special characters
 Calculates password strength score (0–5)
 Displays strength percentage
 Provides suggestions to improve weak passwords.
# Method Used
 Python (loops, conditional statements, functions)
# What I Learned
 String analysis using loops
 Conditional logic
 Function-based program structure
 Debugging and fixing indentation errors
